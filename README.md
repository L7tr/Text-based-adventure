# Vana Kompassi Saladus

Tekstipõhine fantaasia RPG mäng Pythonis.
Mäng sisaldab mitut peatükki, tegelasklasse, lahingusüsteemi, leveldamist, elementaalset arengut, save süsteemi ja loo valikuid.

Veendu, et Python oleks installitud.

Käivita terminalis:

python Peatükk1.py

Chapter 2 kasutab automaatselt Peatükk1.py süsteeme.
